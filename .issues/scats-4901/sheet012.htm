GENERAL NOTES
SUMMARY OF XSF FLAGS
XSF1 - Selects special maximum for SG1 in A using Special Purpose Timesetting No. 12 (All modes).
XSF2 - Freeway Closed for Inbound Traffic. (On line)
XSF4 - Freeway Closed for Outbound Traffic. (On line)
XSF5 Allows detectors 16 and 17 to call E (Master & Flexi).
XSF6 - Selects special maximum for SG4 in D & E using Special Purpose Timesetting No. 13
(All modes).
XSF7 - Selects special maximum for SG5 in B & C using Special Purpose Timesetting No. 14
(All modes).
XSF9 - Selects special maximum for SG9 in B using Special Purpose Timesetting No. 9 (All modes).
SUMMARY OF MSS FLAGS
MSS2 - Set while XSF2 is set.
MSS4 - Set while XSF4 is set.
MSS6 - Set while a queue is detected on detectors 4 and/or 9.
MSS9 - Set while XSF9 is set.
MSS13 - When Special Input 1 changes to ON state set MSS13 (UPS Mains Failure)
MSS14 - When Special Input 2 changes to ON state set MSS14 (UPS Battery Low Warning)
MSS15 - When Special Input 3 changes to OFF state set MSS15 (UPS Malfunction)
GENERAL OPERATION
1.      Clear calls for B if SG9 is green or yellow.
2.      Use A special all red for A red if going AC, AD or AE.
3.      Use C all red for A red if going A→F.
4.      Use C special all red for C red if going C→D.
5.      Use E late start for F late start if going A→F, C→F or D→F.
6.      Use F late start for E late start if going A→E.
SIGNAL GROUP OPERATION
Signal Group 1
SG1 is controlled by Special Movement No.4 in A. A All Red timesetting is substituted for Special Movement timesetting No.4.
XSF1 is used to set the maximum green time for SG1 in A. This time is stored in Special Purpose Timesetting No. 12. SG1 is forced off after this maximum green time in A, which starts at the beginning of SG1 green and includes SG1 minimum green (A minimum green).
Signal Group 2
SG2 closes down at the start of B ECO if going B→D, BE or BF.
Signal Group 3
Early start SG3 in B using a Special Timer (B Special All Red) that starts timing at the end of SG2 yellow if going B→E or B→F.
Late start SG3 in E and F if going A→E, A→F, C→E, C→F, D→E or D→F.
Signal Group 4
Early start SG4 in B using a Special Timer (B Special All Red) that starts timing at the end of SG2 yellow if going B→D.
Early start SG4 in B using a Special Timer (A Special All Red) that starts timing at the end of SG2 yellow if going B→E.
SG4 is controlled by Special Movement No.5 in D and E. E All Red timesetting is substituted for Special Movement timesetting No.5.
XSF6 is used to set the maximum green time for SG4 in D and E. This time is stored in Special Purpose Timesetting No. 13. SG4 is forced off after this maximum green time in D or E, which starts at the beginning of SG4 green and includes SG4 minimum green (D minimum green).
Signal Group 5
Late start SG5 in B and C if going A→B or A→C.
SG5 closes down at the start of B ECO if going B→A, B→D, B→E, B→F.
SG5 is controlled by Special Movement No.6 in B and C. B All Red timesetting is substituted for Special Movement timesetting No.6.
XSF7 is used to set the maximum green time for SG5 in B and C. This time is stored in Special Purpose Timesetting No. 14. SG5 is forced off after this maximum green time in B or C, which starts at the beginning of SG5 green and includes SG5 minimum green (D minimum green).
Signal Group 7
SG7 closes down at the start of F ECO.
Late start SG7 in F using a Special Timer (F Special All Red) that starts timing at the end of SG6 yellow if going C→F or D→F.
Signal Group 9
SG9 is controlled by Special Movement No.1 in B. B All Red timesetting is substituted for Special Movement timesetting No.1.
SG9 closes down at the start of B ECO or during B green if XSF9 is set and Special Maximum Green for SG9 (Special purpose timesetting No.9) is expired.
Signal Group 12
SG12 is controlled by Special Movement No.2 in A. A All Red timesetting is substituted for Special Movement timesetting No.2.
Late start SG12 in A, C, D, E and F using a special timer (E Special all red) that starts timing at the end of SG10 yellow if going B→A, B→C, B→D, B→E or B→F.
Signal Group 13
SG13 is controlled by Special Movement No.3 in A. A All Red timesetting is substituted for Special Movement timesetting No.3.
Late start SG13 in A, C, D, E and F using a special timer (E Special all red) that starts timing at the end of SG10 yellow if going B→A, B→C, B→D, B→E or B→F.

DETECTOR OPERATION
General
Clear vehicle demands during associated phase green and yellow.
Detectors 4 and 9
1.      Detectors 4 and 9 are queue loops.
2.      If the presence timer for detectors 4 and/or 9 have expired, set MSS6.
3.      If detectors 4 and/or 9 are ON for the time in Special Purpose Timesetting No.10, ignore the queue function associated with the detector until the detector has changed state from OFF to ON.
4.      MSS6 can be used to set XSF9 (SG9 maximum) or an Action Item (to set SG9 gap to zero).
Detector 7
Clear demands for F from detector 7 during SG7 green and yellow.
Detector 8
Clear demands for F from detector 8 during SG8 green and yellow.
Detector 12, 13 and 14
Clear demands for B from detectors 12, 13 and 14 during SG9 green and yellow.
Detector 15
Clear demands for B from detector 15 during SG10 green and yellow.
Detector 16 and 17
Clear demands for E and F from detectors 16 and 17 during SG3 green and yellow.
When XSF5 is set, detectors 16 and 17 also call E.
Detector 18 and 19
Clear demands for D and E from detectors 18 and 19 during SG4 green and yellow.
Detector 20, 21 and 22
Clear demands for B from detectors 20, 21 and 22 during SG5 green and yellow.
Detectors 23 and 24
Clear demands for C and D from detectors 23 and 24 during SG6 green and yellow.
FREEWAY INCIDENT MANAGEMENT OPERATION
FREEWAY CLOSED FOR INBOUND TRAFFIC
1.      XSF2 is set when the FREEWAY is CLOSED FOR INBOUND TRAFFIC.
2.      XSF2 is either set via the Freeway Management System (FMS) link to SCATS or manually following confirmation of closure.
3.      When XSF2 is activated, MSS2 is set.
Operation for inbound traffic closure
1.      If XSF2 is set during A, B, C, D or E with no demands for F from detectors 7 or 8 then hold SG7 & SG8 Red.
2.      If XSF2 is set during SG7 and SG8 green (ie. F), then close down SG7. SG8 stays green until end of F.
3.      If XSF2 is set during A, B, C, D or E with demands for F from detectors 7 or 8, allow SG7 and SG8 to run for minimum green.
4.      If the controller goes off-line then clear XSF2 flag and resume normal operation.
Operation of detectors
The operation described below occurs for the time that XSF2 Flag is set.
1.      Inhibit detector 7 and 8 from calling and extending F.
Operation of phases
The operation of phases is modified as described below.
The operation described below occurs for the time that the XSF2 Flag is set.
A Phase
No Change.
B Phase
No Change.
C Phase
         No Change.
D Phase
         No Change.
E Phase
         No Change.
F Phase
If in F when XSF2 is set, then close down SG7 immediately without violating minimum green and hold SG7 and SG8 Red in F.
Freeway reopened for inbound traffic
When XSF2 is cleared, resume normal operation.
FREEWAY CLOSED FOR OUTBOUND TRAFFIC
1.      XSF4 is set when the FREEWAY is CLOSED FOR OUTBOUND TRAFFIC.
2.      XSF4 is either set via the Freeway Management System (FMS) link to SCATS or manually following confirmation of closure.
3.      When XSF4 is activated, MSS4 is set.
Operation for outbound traffic closure
1.      If XSF4 is set during A, C, D, E or F with no demands for B from detectors 12, 13, 14 or 15 or Q- then hold SG9, SG10 & SG11 Red.
2.      If XSF4 is set during SG9 green (ie. B), then close down SG9. SG10 & SG11 stays green until end of B.
3.      If XSF4 is set during A, C, D, E or F with demands for B from detectors 12, 13, 14 or 15 or Q-, allow SG9 to run for minimum green.
4.      If XSF4 is set during A, C, D, E or F, close down SG12 and SG13 after minimum green (D minimum green) and hold SG12 and SG13 red.
5.      If the controller goes off-line then clear XSF4 flag and resume normal operation.
Operation of detectors
The operation described below occurs for the time that XSF4 Flag is set.
1.      Inhibit detector 12, 13, 14 and 15 or Q- from calling and extending B.
Operation of phases
The operation of phases is modified as described below.
The operation described below occurs for the time that the XSF4 Flag is set.
A Phase
If in A when XSF4 is set, then close down SG12 and SG13 immediately without violating minimum green (D minimum green) and hold SG12 and SG13 Red in A.
A ECO is used to guarantee SG12 and SG13 minimum green when XSF4 is cleared during A green. A ECO is expired when not going to B or SG12 and SG13 minimum green is expired.
B Phase
If in B when XSF4 is set, then close down SG9 immediately without violating minimum green and hold SG9, SG10 & SG11 Red in B.
C Phase
If in C when XSF4 is set, then close down SG12 and SG13 immediately without violating minimum green (D minimum green) and hold SG12 and SG13 Red in C.
D Phase
If in D when XSF4 is set, then close down SG12 and SG13 immediately without violating minimum green (D minimum green) and hold SG12 and SG13 Red in D.
E Phase
If in E when XSF4 is set, then close down SG12 and SG13 immediately without violating minimum green (D minimum green) and hold SG12 and SG13 Red in E.
F Phase
If in F when XSF4 is set, then close down SG12 and SG13 immediately without violating minimum green (D minimum green) and hold SG12 and SG13 Red in F.
Freeway reopened for outbound traffic
When XSF4 is cleared, resume normal operation.
UPS ALARM OUTPUTS
To monitor the state of the UPS operation (Uninterrupted Power Supply unit) connected to this traffic signal controller. Three external inputs in the traffic signal controller software personality constantly monitor the condition of the UPS Alarm outputs. They are as following:
Special Input 1 - Mains Failure
A Mains Failure alarm is set when the Special input 1 input (UPS contact C1 output) change from a Normally Off (N/O) state to an On state (ie short circuit, N/C).
When Special input 1 changes state to ON, it sets the MSS13 flag until the external input change state to OFF Again.
The MSS13 flag provides information via SCATS to TMC that the UPS has detected a Mains Failure Alarm
The traffic signal controller is now Running on Batteries Power- the UPS unit has switched from 240 volt mains operation to battery power operation.
Special Input 2 - Battery Low Warning
A Battery Low Warning alarm is set when the Special input 2 input (UPS contact C2 output) change from a Normally Off (N/O) state to an On state (ie short circuit, N/C).
When Special input 2 changes state to ON, it sets the MSS14 flag until the external input change state to OFF again.
The MSS14 flag provides information via SCATS to TMC that the UPS has detected a Battery Low Alarm.
Special Input 3 - System Malfunction
A System Malfunction alarm is set when the Special input 3 input (UPS contact C3 output) change from a Normally On (N/C) state to an Off state (ie open circuit, N/O).
When Special input 3 changes state to OFF, it sets the MSS15 flag until the external input change state to ON again.
The MSS15 flag provides information via SCATS to TMC that the UPS has a System Malfunction Alarm.

OPERATION OF PREPARE TO STOP SIGN
A flashing PREPARE TO STOP located on the westbound exit ramp sign is driven by Special Output 2.
Special Output 2 is switched on at the start of E ECO (if not going to F) or in F ECO when the remaining time in ECO is equal to E ECO. SO2 is switched off when the SO2 timer is expired (SO2 timer is using Special Purpose Timesetting No.11) that starts timing at the start of SG3 green.
